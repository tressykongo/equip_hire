# Equip-Hire – Construction Equipment Rental Platform
Project Overview
Equip-Hire is a web-based construction equipment rental platform developed using Django. It connects construction equipment owners with contractors and individuals who need equipment for temporary use.
The platform provides a convenient way for equipment owners to advertise their equipment and for renters to browse available equipment and submit rental requests.
# Main Features
1. User Registration and Authentication
Users can create accounts and log in.
Users can register as either Equipment Owners or Equipment Renters.
Users are redirected to dashboards according to their account type.
2. Equipment Owner Features
Add construction equipment listings.
Upload equipment photographs.
Provide equipment descriptions, categories and rental prices.
Edit existing equipment listings.
Delete equipment listings.
3. Equipment Renter Features
Browse available construction equipment.
View equipment details and rental prices.
Submit rental requests.
View submitted rental requests and their statuses.
4. Rental Management
Equipment owners can manage rental requests.
Rental requests have Pending, Accepted and Rejected statuses.
